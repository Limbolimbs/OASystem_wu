# 提出物の確認

## 含めるもの

- OA・独立管理コンソールのソース、公開設定例、SQL資源、テストコード、Maven Wrapper。
- README、段階成果、操作確認ガイド、今回の検証結果。
- Excel詳細設計書は別の設計書アーカイブへ収録する。履歴・書式・図を保持する。
- 画面例は合成データを使用し、実社員や秘密情報を含めない。

## 含めないもの

- 本機のOA接続設定、DBユーザー・パスワード、実業務データ、DBダンプ。
- 管理者の初期パスワード、TOTP登録キー・QR、招待コード、DPAPI、秘密鍵、私的PKCS12。
- `.git`、`target`、保守領域、キャッシュ、実行ログ、過去の配布JAR。
- 個人PCの接続情報を含むスクリーンショット、認証Cookie。

旧targetや過去の保守用JARには本機設定が含まれる可能性がある。フォルダーを丸ごとアップロードしない。
公開設定例には実値を記入せず、提出先の接続情報は権限を持つ担当者が非公開で設定する。

## 提出直前

1. 変更・削除・未追跡ファイルを確認し、意図しない削除をステージしない。
2. 既知秘密の照合に加え、設定・スクリーンショット・設計書に秘密がないか確認する。
3. 対象アーカイブのSHA-256を照合する。
4. 提出先の検証用DBと管理者設定を別に用意する。本人の運用設定を配布しない。
5. 自動試験と実環境の本人ログイン確認を区別し、未実施を合格として記載しない。

本アーカイブはGitの履歴・ステージ状態を変更しない。Gitへ提出する場合は、別途レビューして対象を指定する。
