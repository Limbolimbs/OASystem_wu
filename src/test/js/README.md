# AJAX画面の回帰テスト

既存のEdgeをヘッドレスで起動し、テスト内で定義したHTML・JSON応答だけを使用する。
アプリケーションの起動、localhostへのアクセス、実データベースへの接続は行わない。
jQuery 3.7.1のみ公式CDNから取得してメモリー上で再利用し、実際の`$.ajax`（XHR）を検証する。
ローカルへのライブラリ保存は行わない。テスト実行時はcode.jquery.comへの接続が必要。

## 実行条件

- Node.js
- Node.jsから参照できるPlaywright（通常のnode_modules、またはNODE_PATHで指定した既存環境）
- Microsoft Edge。別ブラウザを使う場合は`OA_BROWSER_CHANNEL`でPlaywrightのchannelを指定する。

プロジェクトルートから実行する。

```powershell
node --test src/test/js/page-interactions.test.cjs
```

## 確認対象

- 申請・取消・承認などのJSON応答後の部分取得
- 入力エラー時の入力内容保持、別フォームの草稿保持
- 検索・ページ移動時の部分更新
- 送信中の二重クリック、同じ申請の承認・差し戻しの同時送信防止
- 保存成功後の表示取得失敗時に、GETのみ再実行すること
- 権限更新後の社員検索の再適用
- 同名チェックボックスの全件送信
- セッション切れのログイン画面遷移、予期しないHTMLの取込み拒否
- ログインの成功・失敗・未入力・通信エラー・Enter連打
- ダッシュボードの数値・一覧・グラフへの反映と権限エラー
- 各HTMLのjQuery読込み順序と通信処理に別方式が混在していないこと
- 新規パスワードの12～128文字・4種類中3種類以上・確認入力一致
- 独自確認ウィンドウの取消・Escape・フォーカス復帰・二重送信防止・狭幅表示
- ブラウザーのalert/confirm/promptを使用せず、日本語の欄内エラーを表示すること
- 共通CSRFを同一オリジンPOSTだけに付加し、外部へ送信しないこと
- CSRF読込み不備時の通信中止・ボタン復帰、403時の草稿保持・POST再送禁止
- ログアウトのCSRF付きPOSTと成功後のログイン画面遷移
- 営業実績の登録・版数付き編集・競合時の入力保持、保存後の部署選択の復帰
- ダッシュボードの再取得時に同じグラフを再利用し、ページ遷移しないこと

先に`mvnw.cmd test`を実行すると、MVCテストが実Thymeleafの画面を`target/ui-preview`へ出力します。
その後に上記Nodeテストを実行すると、営業実績・部署管理をモック応答で表示して整頁PNGも生成します。
生成HTMLがない場合は、この2件の画面確認だけをスキップします。モック応答は実データではありません。

ブラウザライブラリ・キャッシュを新規導入する場合はDドライブを使用する。
